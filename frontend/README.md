# EKSBASE Report Frontend - Models Inline

This revision changes the table presentation:

- Area rows remain the page-level drill-down:
  District -> Region -> Sub-Region -> Store -> Promoter
- Models are shown automatically under each Area row by default.
- There is no separate "Model Performance" section.
- Model rows can be expanded inline to show Color rows.
- Clicking the Area name/row navigates to the next Area level.
- Stock is blank/— at Promoter level.
- Default date remains today to today.
- Detailed Inventory and Sell-out records remain in Excel export.
